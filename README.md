# Hong Kong Rainfall

## The phenomenon

This project visualises daily rainfall in Hong Kong during 2026.

The visualisation shows how rainfall changes over time and helps reveal periods with higher and lower rainfall.

## The source

The data comes from the Hong Kong Observatory open data.

The dataset contains daily total rainfall recorded at the Hong Kong Observatory station.

## What the picture shows

The chart shows daily rainfall across 2026.

Each point represents the total rainfall recorded for one day. The visualisation makes changes and rainy periods easier to see over the year.
